# Student Skill Exchange Platform

## 📌 Project Description

The **Student Skill Exchange Platform** is a web-based application that allows students to share their skills and learn new skills from other students.

Students can register by providing their name, email, the skill they can teach, and the skill they want to learn. The platform displays registered students and helps users find other students who can teach the skill they are interested in learning.

This platform encourages peer-to-peer learning, collaboration, and knowledge sharing among students.

## ✨ Features

- **Student Registration:** Students can register with their personal details.
- **Teach a Skill:** Students can mention the skill they know.
- **Learn a Skill:** Students can select the skill they want to learn.
- **View Students:** Display all registered students.
- **Smart Skill Matching:** Find students who can teach the skill you want to learn.
- **Database Integration:** Store student information in MongoDB Atlas.
- **Duplicate Email Validation:** Prevent registration with an already registered email.
